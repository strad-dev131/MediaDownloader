Place your background music file in this folder and name it exactly:

music.mp3

Supported formats: MP3 (preferred), M4A, OGG (you may add additional <source> tags in index.html if needed).

Notes:
- The Play Music / Pause Music button in the site header controls this audio.
- The player uses <audio id="bgMusic" preload="auto" loop> and starts only on user interaction (click) due to browser policies.
- Default volume is set to 0.6 in main.js. Adjust if desired.
- If you change the filename, also update the <source src="./assets/music/your-file.ext"> in index.html.
